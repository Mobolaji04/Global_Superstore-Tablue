# 📊 Global Superstore Tableau 


## 🚀 Project Overview

This project demonstrates advanced Tableau visualization and business intelligence skills using the **Global Superstore Dataset**, a multinational retail dataset containing sales transactions across multiple countries, product categories, customer segments, and regions.

The goal is to transform raw business data into actionable insights through interactive dashboards and visual storytelling.

---

## 📂 Dataset Overview

### Key Fields

| Category | Fields |
|-----------|---------|
| Orders | Order ID, Order Date, Ship Date, Ship Mode |
| Customer | Customer ID, Customer Name, Segment |
| Geography | Country, State, City, Region, Market |
| Products | Category, Sub-Category, Product Name |
| Metrics | Sales, Profit, Quantity, Discount, Shipping Cost |
